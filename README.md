## 1. Требования

    Операционная система: Linux (протестировано на Ubuntu / WSL)

    Компилятор: GCC с поддержкой стандарта C++17

    Система сборки: CMake (версия 3.10 или выше)

    Язык Python: Версия 3.x с установленным пакетным менеджером pip

## 2. Подготовка

## 3. Запуск
```bash
chmod +x start_simulation.sh

./start_simulation.sh <путь_к_конфигурационному_файлу>
```
Пример:
```bash

./start_simulation.sh tests/test2.txt 
```

## 4. Формат входного файла (две строки)

    Программа принимает текстовый файл, состоящий строго из двух строк:

    Первая строка: Время симуляции в секундах (число с плавающей точкой <= 3600).

    Вторая строка: Название модели и её параметры через пробел.

    Поддерживаемые модели:

Равномерная (uniform:)
Формат: uniform: <интервал_между_пакетами> <размер_пакета>
Пример (test.txt):

```bash
100.0
uniform: 10 10
```

Пуассоновская (poisson:)
Формат: poisson: <лямбда_интервала> <лямбда_размера>
Пример (test2.txt):

```bash
1.0
poisson: 100 10
```


## 5. Что происходит при запуске

    Симуляция (C++): Программа считывает конфигурационный файл, генерирует пакеты по выбранным математическим законам и сохраняет промежуточный результат в файл result.csv.

    Анализ и графики (Python): Скрипт python/gui.py автоматически считывает этот CSV-файл, выводит метрики в консоль и открывает графическое окно.
